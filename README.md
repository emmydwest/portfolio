# Emmy D West

Portfolio of Emmy D West (Emmanuel Ebipador Kalama), a full-stack developer in Lagos, Nigeria, and founder of [Ashabi](https://ashabi.cloud).

The page keeps the navy, gold, and ivory palette and the Cormorant Garamond and Manrope type from the live Ashabi site. The portrait is the public X profile image. Project pictures are screenshots of [ashabi.cloud](https://ashabi.cloud) and of Retro OS 95 running locally.

## Work

- **[Ashabi](https://ashabi.cloud)** — African-founded platform for comics, webtoons, graphic novels, and serialized illustrated fiction. Founder’s edition, Lagos, in active development. Titles currently loaded through a third-party integration are demonstration content, not Ashabi Originals.
- **[Retro OS 95](https://github.com/emmydwest/retro-os-95)** — A 1990s desktop in the browser, built with TypeScript, React, and Vite. Windows, Notepad, a calculator, themes, CRT scanlines, and Web Audio sounds.

The Retro OS 95 repository lists `https://retro-os-95.vercel.app` as its homepage. That deployment was not found, so the portfolio links to the source and shows a screenshot of the interface.

## Develop

Node.js 22 or newer.

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

`npm run build` typechecks, then writes the static site to `dist/`.

## Libraries

React, Vite, and TypeScript. Motion is [GSAP](https://gsap.com) ScrollTrigger and [Lenis](https://github.com/darkroomengineering/lenis) on desktop; phones keep native scrolling. Icons are [react-icons](https://react-icons.github.io/react-icons/) Simple Icons. Type is Cormorant Garamond and Manrope, self-hosted with Fontsource. All of these are free to use.
